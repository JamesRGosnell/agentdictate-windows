AgentDictate for Windows 10/11 (x64)

Extract the entire ZIP, then double-click install.cmd. No administrator access is needed.
Open AgentDictate from its desktop shortcut or Start. In Settings choose ChatGPT subscription, then Sign in with ChatGPT.
An installed Codex CLI or Codex desktop distribution providing codex.exe is required for this route.
AgentDictate keeps its browser sign-in in LocalAppData\AgentDictate\codex-login and preserves your normal Codex configuration.
No paid OpenAI API key is needed for subscription dictation. Optional AI cleanup still uses the upstream API route when explicitly configured.

Set your preferred shortcut in Settings, save it, focus a text field, and dictate.
Toggle mode starts/stops on successive presses; Hold mode records while the shortcut is held.
Escape cancels. The tray menu opens Settings, starts dictation, or quits the background app.
Enable Launch at login in Settings to start the background app after Windows sign-in.

Windows security prevents normal applications from injecting into elevated/admin windows or the secure desktop.
For an elevated destination, use Recovery > Copy and paste manually, or run both applications at matching permissions.
Transcripts remain recoverable when clipboard/paste delivery fails.

Settings, history, recordings, and logs: %LOCALAPPDATA%\AgentDictate
Installed binaries: %LOCALAPPDATA%\Programs\AgentDictate
Uninstall through Windows Installed apps; personal data is retained.
Portable use: run agentdictate.exe directly from the extracted folder.
